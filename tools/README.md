# tools

오케스트레이션이 아니라 **QA 도구**다. `core/` 는 대상 프로젝트의 `.claude/` 로 그대로 복사되는 것인데
이쪽은 성격이 다르다. 파이프라인의 일부가 아니라 따로 돌려 보는 검사다.

지금 들어 있는 것은 안드로이드 프로젝트에서 반입한 원본이라 **그 제품의 리소스 경로와 adb 에 묶여 있다.**
현 상태로는 이식 불가다. 버리지 않고 여기 둔 이유는 아래 통찰이 스택 무관하기 때문이다.

| 디렉토리 | 살릴 개념 |
|---|---|
| `i18n/` | 문자열을 코드에서 이어 붙이면 어순이 다른 언어에서 깨진다. 동적 검사로는 못 잡는 사각이다 (`i18n_concat_check.py`)<br>리소스 파일 간 키 누락 검사는 모든 i18n 스택 공통 개념이다 (`i18n_static.py`) |
| `crash-hunt/` | 런타임 게이트와 상보적인 두 번째 검증 축이다. 게이트는 "어제 되던 게 오늘도 되나", 이건 "죽는 데가 있나" 를 묻는다.<br>무작위 입력이 실계정 기기에서 되돌릴 수 없는 동작을 일으키는 것을 막는 동의 게이트도 이식 가치가 있다 |

`i18n/` 의 나머지 넷(`scan` `scan_all` `report` `source_rank`)은 E2E 시나리오 자산과 adb 에 묶여 있다.
같이 옮겨 두고 일반화는 나중에 판단한다.

## 프로젝트 값은 환경변수로 준다

스택 결합(adb, 안드로이드)은 남아 있지만 **특정 제품 값은 코드에 없다.**
기본값을 두지 않은 것은 의도다. 엉뚱한 앱에 무작위 입력을 쏟거나 엉뚱한 경로를 훑는 사고가
조용히 일어나면 안 된다. 안 주면 실행을 거부한다.

| 변수 | 쓰는 곳 | 뜻 | 없으면 |
|---|---|---|---|
| `HUNT_CONFIRM` | `crash-hunt/` | 실기기 무작위 입력에 대한 명시적 동의. `1` 이어야 실행 | 차단 (exit 3) |
| `HUNT_PKG` | `crash-hunt/` | 두들길 앱 패키지 | 차단 (exit 3) |
| `HUNT_SRC_PREFIX` | `crash-hunt/` | 우리 코드로 인정할 스택트레이스 접두사 | 그 분류 항목만 건너뜀 |
| `I18N_PKG` | `i18n/scan` | 검사할 앱 패키지 | 차단 (exit 3) |
| `I18N_SRC` | `i18n/` 정적 검사 | 소스 루트 경로 | 찾지 못하면 exit 2 |
| `I18N_REPO` | `i18n/` | 저장소 루트 (생략 시 스크립트 위치 기준) | 자동 산출 |
