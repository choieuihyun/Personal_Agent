# tutor: 공식 문서와 이 프로젝트 코드를 나란히 놓고 설명해 주는 AI

## 무엇을 하나

tutor 는 배우고 싶은 개념이나 파일을 받으면 두 가지를 나란히 보여 주며 설명해요.
하나는 공식 문서와 공식 예제 코드가 말하는 방식이에요.
다른 하나는 이 프로젝트 코드가 실제로 쓰는 방식이에요.
둘이 다른 곳이 바로 배울 곳이에요.
tutor 는 문서를 요약만 하지 않아요. 코드도 고치지 않아요.

## 언제 불리나

| 커맨드 | 단계 |
|---|---|
| `/study` | 첫 번째 단계예요. 사용자가 준 주제를 그대로 받아서 공식 쪽과 이 프로젝트 쪽을 비교한 보고를 만들어요 |

## 못 하는 것

- tutor 는 이 저장소의 파일을 고치지 못해요. 고치는 도구(Edit, Write)를 아예 주지 않았어요. 공부 도구가 코드를 바꾸면 배운 것과 바뀐 것이 섞이기 때문이에요. 딱 하나 예외가 있어요. 저장소 밖의 예제 보관 폴더에 공식 예제 코드를 내려받는 일은 해요
- 이 저장소에서 git 명령을 쓰거나 명령 실행(Bash)으로 파일을 쓰지 않아요. 이건 지시문으로 막은 것이고, 도구로 막지는 못했어요(명령 실행 도구 Bash 가 있어요)
- 학습 노트를 직접 저장하지 못해요. 쓰기 권한이 없기 때문이에요. `/study --note` 로 부르면 `/study` 를 실행한 본 대화의 AI 가 대신 저장해요

## 넘겨주는 것

tutor 는 학습 보고와 확인 문제를 넘겨요.
학습 보고에는 개념마다 네 가지를 붙여요.
한 줄 정의, 왜 그렇게 동작하는지, 공식 예제의 위치(파일:줄), 이 저장소의 위치(파일:줄)예요.
`/study` 는 이 보고를 터미널에 그대로 보여 줘요.
`--note` 를 붙이면 학습 노트 폴더(`docs.study_dir`)에 날짜가 붙은 파일로도 남겨요.

## 여기에 넣으면 좋아지는 것

- 공식 예제 코드가 모인 저장소를 정해 주세요. 안드로이드는 공식 샘플 저장소, 웹은 프레임워크 예제 저장소, 서버는 언어의 공식 예제 같은 곳이에요. 정해 주시면 tutor 가 문서 설명보다 강한 근거인 실제 코드로 비교해요
- 이 프로젝트 코드가 있는 최상위 폴더를 알려 주세요. 앱은 `app/src/main`, 웹은 `src/`, 서버는 `internal/` 같은 곳이에요. 알려 주시면 tutor 가 이 프로젝트에서 실제로 쓰는 곳을 찾아 공식 예제와 짝지어 줘요
- 공부 재료로 쓸 작은 파일을 골라 주세요. 수천 줄짜리 파일 대신 읽기 좋은 작은 파일을 정해 주시면 설명이 짧고 정확해져요
- 예제 저장소에서 내려받을 파일 종류를 정해 주세요. `**/*.kt`, `**/*.tsx`, `**/*.go` 처럼 정하면 예제 저장소를 수십 MB 정도로 가볍게 받아요

## 질문

| # | 사용자에게 할 질문 | 스캔으로 추측 | 저장 위치 | 안 채우면 |
|---|---|---|---|---|
| 1 | 공부할 때 기준으로 삼을 공식 예제 코드 저장소가 있나요? 예를 들어 쓰고 있는 프레임워크의 공식 샘플 저장소 같은 곳이요 | 주로 쓰는 프레임워크를 보고 그 공식 샘플 저장소를 후보로 골라요 | `learning.sample_repos` | tutor 가 예제 코드 없이 공식 문서만 보고 설명해요 |
| 2 | 예제 저장소를 내려받아 둘 폴더는 어디로 할까요? 이 저장소 밖이어야 해요. 예를 들어 홈 폴더 아래 `~/.cache/samples` 같은 곳이요 | 알 수 없음. 홈 폴더 아래 보관 폴더를 제안해요 | `learning.cache_dir` | tutor 가 예제 코드 없이 공식 문서만 보고 설명해요. 이 저장소 안의 폴더를 알려 주시면 내려받지 않고 그 사실을 알려요 |
| 3 | 예제 저장소에서 어떤 종류의 소스 파일을 받아 둘까요? 예를 들어 `.kt` 파일이나 `.tsx` 파일 같은 것이요 | 이 저장소에 많은 파일 확장자 | `learning.source_globs` | 설명 문서(.md)만 받아요. 그러면 비교할 예제 코드가 없어요 |
| 4 | 이 프로젝트에서 실제로 쓰는 곳을 찾을 코드 폴더는 어디인가요? 예를 들어 `src/` 나 `app/src/main` 같은 곳이요 | `src/`, `app/src/main` 같은 흔한 폴더 | `learning.source_root` | tutor 가 이 프로젝트 코드와 비교하지 못해요. 그러면 공부가 문서 요약에 그쳐요 |
| 5 | 공부 재료로 쓰기 좋은 작은 파일을 몇 개 골라 주시겠어요? 예를 들어 짧고 다른 파일을 많이 가져다 쓰는 화면 파일 같은 것이요 | 코드 폴더 안에서 줄 수가 적고 다른 파일을 많이 가져다 쓰는(import) 파일 | `learning.small_samples` | 아주 큰 파일이 공부 재료로 뽑힐 수 있어요 |
| 6 | 학습 노트를 모아 둘 폴더는 어디로 할까요? 예를 들어 `docs/study` 같은 곳이요 | `docs/study` 같은 이미 있는 폴더 | `docs.study_dir` | `/study --note` 로 불러도 파일을 남기지 않아요. 남기지 못했다는 사실만 알려요 |
