# implementer-modernize: 옛 건물을 새 공법으로 다시 짓되 방 배치는 그대로 두는 리모델링 담당

## 무엇을 하나

낡은 언어나 화면 방식으로 된 코드를 새 방식으로 옮겨 쓴다. 겉모습은 새로 바뀌지만 동작은 원본과 1:1 로 같아야 한다.
허가받은 파일 안에서만 고치고, 새로 만든 화면, 모듈, 엔드포인트는 프로젝트의 완료 기준을 채우도록 쓴다.
의도적으로 동작을 바꾼 곳은 주석으로 남긴다.

## 언제 불리나

| 커맨드 | 단계 |
|---|---|
| `/modernize` | 2단계 마이그레이션 수정 (IMPLEMENTING). 1.5단계에서 수정 전 baseline 시나리오를 뜬 뒤에 불린다 |
| `/modernize` | 3단계 검증 + 빌드가 실패하면 verifier 지적과 빌드 에러를 받아 다시 불린다 |

## 못 하는 것

- 명령 실행 (Bash 없음): 빌드, git, 완료 기준 검사 스크립트를 못 돌린다. 검사는 verifier 가 돌린다
- 검색 (Grep, Glob 없음): 범위는 explorer 가 정한다. 옮기다가 범위를 넓히지 못하게 한다
- 허가 목록 밖 파일, 빌드 설정 파일 수정 (규칙): 범위 밖 변경은 검증되지 않는다
- 동작 로직 재작성, 없는 패턴 도입, API 변경 (규칙): 옮기기와 고치기를 섞으면 회귀가 어디서 났는지 못 가린다

## 넘겨주는 것

코드는 파일에 직접 반영하고 최근 패치 기록을 남긴다 (implementer 와 같은 형식).
verifier 가 원본과 비교하고 완료 기준을 검사하며, builder 가 컴파일한다.
그 뒤 런타임 게이트가 수정 전에 떠 둔 시나리오로 동작이 보존됐는지 재생한다.

## 여기에 넣으면 좋아지는 것

- 전환 방향(레거시 언어와 UI, 목표 언어와 UI)을 알려 주면 매번 인테이크에서 묻지 않는다. 예: 모바일의 선언형 UI 전환, 웹의 타입 도입, 서버의 언어 교체
- 완료 기준 중 기계로 확인되는 것을 규칙으로 주면 쓰는 단계부터 지키고 verifier 가 기계로 확정한다. 예: 새 화면 파일에 미리보기 함수 필수, 새 엔드포인트에 입력 검증 필수, 옛 방식 API 호출 금지
- 공존 기간의 상호운용 주의점(레거시 코드가 새 코드를 부를 때 필요한 표기 등)을 알려 주면 컴파일은 되는데 실행에서 죽는 일이 준다
- 기준 구조(이미 전환이 끝난 참조 화면)는 컨벤션 문서에 적는다. implementer 설명서의 `docs.conventions` 질문에서 함께 받는다

## 질문

| # | 사용자에게 할 질문 | 스캔으로 추측 | 저장 위치 | 안 채우면 |
|---|---|---|---|---|
| 1 | 옮겨 갈 목표 언어는 무엇인가 | 최근 추가된 소스 파일의 확장자 | `stack.language` | `stack` 전체가 비면 전환 방향을 몰라 `/modernize` 인테이크에서 묻는다. 이 키 하나만 빈 경우의 동작은 뼈대에 정해져 있지 않다 |
| 2 | 옮겨 오는 레거시 언어는 무엇인가 | 오래된 파일 쪽 확장자 비율 | `stack.legacy_language` | 위와 같다 (한 키만 빈 경우는 정해져 있지 않다) |
| 3 | 화면 방식도 옮기는가. 목표 UI 방식은 (언어와 UI 가 둘 다 설정되면 한 화면에서 함께 옮긴다. 반쪽 전환은 하지 않는다) | UI 프레임워크 의존성 | `stack.ui` | 위와 같다 (한 키만 빈 경우는 정해져 있지 않다). 화면이 없으면 비워 둔다 |
| 4 | 옮겨 오는 레거시 UI 방식은 | 레이아웃 파일이나 템플릿 폴더 | `stack.legacy_ui` | 위와 같다 (한 키만 빈 경우는 정해져 있지 않다) |
| 5 | 새 화면, 모듈, 엔드포인트가 반드시 갖춰야 하는 것 중 파일 내용으로 확인되는 것은 (필수 포함, 금지 문자열) | 이미 전환된 파일들의 공통 패턴 | `dod_checks` | 기계 검증을 못 했다고 보고한다. 통과가 아니다 |
| 6 | 옮길 때 이 프로젝트만의 순서나 피할 곳이 있는가 (예: 공용 컴포넌트는 마지막에) | 불가 | `.claude/project/agents/implementer-modernize.md` | 컨벤션 문서와 주변 코드만 따른다 |
